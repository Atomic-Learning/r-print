In R the print function is used to display output. This can be useful for reporting results to the user or debugging code. To use it, write the word print followed by parentheses containing the values you wish to print, such as in the example below:

print(42) The output will be often preceded by a number in square brackets, such as `[1]`. You can ignore this for now; it is used to indicate the index of the first element in the output line.

By default, the print function adds a newline character at the end of the output, which means that subsequent print statements will appear on a new line:

print(10) print(9)
